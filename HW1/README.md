# Econometrics II - HW I
=========================

## Overview

This repository contains materials for analyzing gender disparities in employment trends using Iran's Labor Force Survey (LFS) data. The project involves exploring gender distribution across sectors, assessing average hours worked, and investigating reasons for job leave among males and females.
------------------------

## Prerequisites

Before running the scripts, ensure the following:

*   R programming language installed.
*   RStudio installed for a more convenient development environment.
*   Required R packages installed:
    *   knitr
    *   RODBC
    *   dplyr
    *   tibble
    *   ggplot2
    *   tidyverse
    *   lemon
    *   reshape2

You can install these packages using the `install.packages()` function in R.
------------------------

## Data

The dataset used is extracted from the Statistical Center of Iran (SCI)'s Labor Force Survey (LFS), covering employment data from 1397 to 1401 (Solar Hijri calendar).
